# 기능 명세서 (Features Specification)

모바일 및 폴더폰 환경에 맞춘 초심플 3단계 배리어프리 셀프오더 PWA 명세입니다.

---

## 1. 초기 로딩 화면 (Loading Screen)
- 앱 진입 시 "프로토타입" 로딩 바 단독 노출.
- 로딩 완료 시 위쪽으로 슬라이드업 오프 트랜지션.

---

## 2. 첫 번째 화면 (Step 1: 장애인 / 비장애인 선택)
- 화면 중앙에 수직으로 거대하게 배치된 2개의 선택 버튼만 단독 노출.
- 🟡 **장애인 지원**: 노란색 바탕 + 검정 굵은 선 및 블록 그림자 버튼. 클릭 시 Step 2(유형 선택) 이동.
- ⚪ **비장애인**: 클릭해도 아무 동작 안 함 (비활성).

---

## 3. 두 번째 화면 (Step 2: 유형 선택 재배열)
요청된 순서대로 직관적인 거대 카드로 재배열:
1. 👁️ **시각 장애** (1순위)
2. 🧠 **난독증 / 고령자** (2순위)
3. ♿ **지체 장애** (3순위)
4. 🦻 **청각 장애** (4순위)

---

## 4. 네이티브 스크린 리더 (VoiceOver / TalkBack) 완벽 지원
- 웹 브라우저 자체의 커스텀 음성 합성(TTS) 중복을 배제하고, iOS **VoiceOver** 및 Android **TalkBack** 표준 네이티브 스크린 리더가 자동으로 읽을 수 있도록 WAI-ARIA 규격 (`aria-label`, `role="region"`, `role="status"`, `aria-live="polite"`, `focus:ring`)을 적용.

---

## 5. 세 번째 화면 (Step 3: 맞춤형 주문)
- 2개의 직관적인 거대 메뉴 선택지 (아메리카노 / 녹차) 및 하단 주문하기 버튼이 중앙 배치.
- 주문 완료 시 대기번호(예: 102)만 노란색 카드 형태로 거대하게 단독 표출.
- [처음으로] 버튼으로 원터치 리셋 지원.
